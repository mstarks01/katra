## Reproduction

Every command runs offline, from a checkout at `2235a71c`. `evals/runs/` is not in git, so the commands run only on the maintainer's machine.

```bash
KATRA_OFFLINE=1 PYTHONPATH=src:. uv run python evals/experiments/QA-2026-11-24-01/trace.py \
  evals/runs/20261024T-sonnet-medium-sweep evals/corpus \
  evals/experiments/QA-2026-11-17-13/verb-rows.csv evals/experiments/QA-2026-11-24-01
python3 evals/experiments/QA-2026-11-24-01/manifest.py \
  evals/runs/20261024T-sonnet-medium-sweep evals/experiments/QA-2026-11-24-01/manifest.json
```

`manifest.py` writes the run's directory name, so the command rebuilds `manifest.json` byte for byte. `trace.py` raises on a cause it has no rule for, so a later sweep with a `position`, `merged`, `misfiled`, `critic` or `fan-in` miss stops the script rather than getting a false attribution.
